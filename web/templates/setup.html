初次安装步骤
1
准备环境与依赖

Python 3.11+（推荐 conda 环境 qdt），安装依赖：

conda create -n qdt python=3.11
conda activate qdt
pip install -r requirements.txt
2
配置 .env

复制模板并填入 LLM API Key（舆情分析/AI 助手用）：

copy .env.example .env
# Linux/Mac: cp .env.example .env
# 编辑 .env 填入 API_KEY=sk-...

不配置 Key 时回测功能完全可用，仅舆情类功能不可用。

3
自检并启动

先自检确认无失败项，再启动服务：

python web_app.py --check-env
python web_app.py

启动后访问 http://127.0.0.1:8000。

4
可选增强
  • 构建 Vue3 SPA：cd frontend && npm install && npm run build
  • 本地缓存层：docker compose up -d（PostgreSQL + Redis）
  • Tushare 数据主源：.env 中设置 TUSHARE_TOKEN
常用命令说明
命令 说明
python web_app.py 启动 Web 服务（默认 127.0.0.1:8000，仅本机访问）
python web_app.py --check-env 安装自检（Python / .env / Key / 前端构建 / 缓存层），存在失败项时退出码为 1
python web_app.py --host 0.0.0.0 --port 8000 监听所有网卡（局域网可访问）。注意暴露风险，也可用环境变量 QDT_WEB_HOST / QDT_WEB_PORT 持久覆盖
pytest test/test_backtest.py -v 运行回测模块测试（其它套件：test_us_data_sources / test_ashare_data_sources / test_trendradar_notify）
cd frontend && npm install && npm run build 构建 Vue3 SPA 到 frontend/dist/（构建后 /spa/* 可用；类型错误会中断构建）
cd frontend && npm run dev SPA 开发服务器（http://localhost:5173/spa/，自动代理 /api 到后端）
docker compose up -d 启动本地数据缓存层（PostgreSQL 16 + Redis 7，端口仅绑定 127.0.0.1）
python -m src.data.db healthcheck 检查数据缓存层连通性（也可访问 /api/health）
关键环境变量（.env）
变量 必填 说明
API_KEY / LLM_BASE_URL / LLM_MODEL推荐舆情分析的 OpenAI 兼容 LLM 配置
AGENT_API_KEY / AGENT_BASE_URL可选AI 投资助手独立配置，留空回退上方 API_KEY / LLM_BASE_URL
TUSHARE_TOKEN可选Tushare Pro token，配置后成为 A 股数据主源（免费源自动兜底）
POSTGRES_* / REDIS_*可选docker compose 启动的本地缓存层连接参数
REDIS_PASSWORD可选设置后 Redis 启用 requirepass，应用自动携带密码
QDT_DB_CACHE_ENABLED / QDT_REDIS_CACHE_ENABLED可选设为 false 关闭对应缓存层（自动降级到 CSV + 网络数据源）
QDT_WEB_HOST / QDT_WEB_PORT可选覆盖服务监听地址/端口（等价于 --host / --port）

完整清单见 .env.example；.env 已被 .gitignore 忽略，请勿提交真实密钥。

安全说明
  • 服务默认只监听 127.0.0.1（仅本机访问）。需要局域网访问时用 --host 0.0.0.0 显式开启，并自行确保网络可信——本项目接口没有内置鉴权。
  • 所有 API Key 只保存在本地 .env（已 gitignore），不会出现在前端页面或接口响应中。
  • docker compose 的 PostgreSQL / Redis 端口仅绑定 127.0.0.1，不会暴露到局域网；Redis 可通过 REDIS_PASSWORD 启用密码。
  • 全站响应带 X-Content-Type-Options / X-Frame-Options / Referrer-Policy 安全头；接口 500 错误不回显内部异常细节。
