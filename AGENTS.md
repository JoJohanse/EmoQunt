# AGENTS.md

Guidance for OpenCode agents working in this repo. EmoQunt is a sentiment-driven A-share/US-stock backtesting platform: FastAPI backend + backtrader, with **two coexisting frontends** (Jinja2 templates served at `/`, and a Vue3 SPA served at `/spa/*`). Internal legacy name is "Qdt_test" (appears in `config.yaml`, FastAPI title, `CONTRIBUTING.md`).

## Commands

### Backend / Python
- Run dev server: `python web_app.py` (uvicorn on `127.0.0.1:8000`, single entrypoint)
- Run tests (pick files explicitly — `test/` also contains scratch scripts):
  - `pytest test/test_backtest.py -v`
  - `pytest test/test_us_data_sources.py -v`
  - `pytest test/test_ashare_data_sources.py -v`
  - `pytest test/test_trendradar_notify.py -v`
- **No** `pyproject.toml`, `pytest.ini`, `conftest.py`, or Python linter/formatter config exists. CONTRIBUTING.md asks for PEP 8 + Google-style docstrings, but nothing enforces it.
- Python 3.11+ in conda env named **`qdt`** (per `.vscode/settings.json` and `test_backtest.py` docstring).
- Heavy deps: `torch`, `transformers`, `modelscope` are in `requirements.txt` (used by LLM/model layer) — installs are large.

### Frontend (Vue3 SPA, `frontend/`)
- Dev server: `npm run dev` (Vite on `:5173`, proxies `/api` → `127.0.0.1:8000`). The SPA router base is fixed to **`/spa/`** (`frontend/src/router/index.ts`), so in dev open `http://localhost:5173/spa/` — the bare `/` shows an empty `<main>` (no route matches).
- Build (served by FastAPI in prod): `npm run build` — runs `vue-tsc -b && vite build`, so **type errors fail the build**. Note `vue-tsc -b` is stricter than `npm run type-check` (`--noEmit` skips project references).
- Build output `frontend/dist/` is auto-served by `web_app.py` at `/assets` + `/spa/*` fallback; if unbuilt, `/spa/*` returns 503.

## Architecture & wiring (non-obvious)

- **Path resolution**: `PROJECT_ROOT` is computed in `src/utils/paths.py` (`parents[2]`). All directory helpers (`get_logs_dir`, `get_output_dir`, `get_config_dir`, `get_stock_data_dir`, `get_web_dir`, `get_frontend_dist_dir`) live there. Never hardcode paths — use these.
- **Env loading order matters**: `src/utils/env.py` loads `.env` idempotently at import time. Entry points and `config/config_loader.py` call `load_env()` at module top *before* any `os.environ.get`. Replicate this pattern in new entry points.
- **Config**: `config/config.yaml` is loaded by the `ConfigLoader` singleton (`get_config()` in `config/config_loader.py`). Env vars with prefix **`QDT_`** override keys (e.g. `QDT_DATA_STORAGE_PATH`). Separate `sentiment_config.yaml` / `scoring_config.yaml` are overridable via `QDT_SENTIMENT_CONFIG_PATH` / `QDT_SCORING_CONFIG_PATH`.
- **Two backtest entrypoints** in `src/backtest/backtest_manager.py`:
  - `run_backtest_with_charts` → returns chart image URLs; used by the Jinja2 `POST /run_backtest`.
  - `run_backtest_json` → returns JSON time series; used by the Vue3 `POST /api/backtest/run`. It also returns `trades` (per-fill `{date, side, price, size}` recorded by the `_TradeRecorder` backtrader analyzer, capped at 500) — the SPA `BacktestView` renders them as B/S `markPoint`s plus an average-cost `markLine` on a K-line fetched with the **same adjust as the backtest core** (`hfq` for zh_a, `qfq` for us), otherwise prices won't align with the candles.
- **Two cost models**: `AShareCommInfo` (asymmetric — stamp duty sell-only 0.05%, min commission 5 RMB, transfer fee both sides) and `USStockCommInfo` (symmetric, no stamp duty). Routed by `market` param: `zh_a` (default, CSI300/000300 benchmark) vs `us` (S&P500/SP500).
- **US stock data: two-tier fallback** (`src/data/data_manager.py`): yfinance (Yahoo Finance, primary — free, no API key, supports start/end) → akshare `stock_us_daily`/`index_us_stock_sina` (Sina source, fallback). yfinance returns uppercase columns (`Open/High/Low/Close/Volume` + tz-aware `Date` index); `_fetch_us_stock_yf`/`_fetch_us_index_yf` normalize to lowercase (`date/open/...`) so the existing `rename_map` in `get_stock_data`/`get_us_index_data` produces the downstream Chinese column contract (`时间/开盘/最高/最低/收盘/成交量`). yfinance `end` is exclusive — code adds +1 day. In China, yfinance is often network-blocked; the akshare fallback ensures availability.
- **A-share stock data: fallback chain** (`src/data/data_manager.py`): Tushare Pro (`pro.daily`/`pro_bar`, **optional primary — gated on `TUSHARE_TOKEN` env var, silently skipped if unset or tushare not installed; ts_code format `600938.SH`, amount in 千元 multiplied ×1000 to 元**) → akshare `stock_zh_a_daily` (Sina) → akshare `stock_zh_a_hist` (Eastmoney — official-recommended, symbol is bare 6-digit code without sh/sz prefix) → baostock `query_history_k_data_plus` (independent data server). Same chain for indices: Tushare `index_daily` → `stock_zh_index_daily` (Sina) → `stock_zh_index_daily_em` (Eastmoney, supports start/end) → baostock. baostock code format is `sh.600000` (dot-separated), dates are `YYYY-MM-DD`, `adjustflag` 1/2/3 means hfq/qfq/nfq (**reversed vs akshare**), volume unit is shares (code divides by 100 to match akshare's 手), and all numeric fields return as strings (code casts to float). `_BaoStockSession` manages login/logout with auto-relogin after 200 queries and exponential-backoff retries.
- **`daily_recommend` no longer touches baostock directly**: `src/factor/daily_recommend.py:get_stock_data` delegates to `Stock(code).get_stock_data(...)` (the chain above) instead of its own standalone baostock login. It adapts the column contract (sets `时间` as a DatetimeIndex, ascending) to preserve the `tail(N)`/`iloc[-1]` semantics its scoring functions depend on. Its own two-layer cache (`STOCK_DATA_CACHE` dict + `stock_data/stock_cache/*.csv` with 1-day freshness) wraps the fetch unchanged.
- **Strategy system**: built-in backtrader strategies are registered in `global_strategy_manager` (`src/Strategy/Strategy.py`). User strategies are JSON in `src/Strategy/user_strategies/strategies.json` based on the `sentiment_ma` template, materialized into classes via `create_user_strategy_class`. Parameter parsing: `extract_param_value` accepts **both** `value` (user-saved) and `default` (template) keys, with `value` winning.
- **Strategy list cache**: owned by `src/services/strategies.py`（谁写谁失效）via `src/utils/ttl_cache.py` 的 `TTLCache`（5 分钟，启动经 `ensure_loaded()` 预热）——mutation 函数同 module 自动失效，**不要再写手动 clear 调用**（旧的全局 `_strategy_cache` + 4 个 handler 手动 clear 已删除，AGENTS 早前的对应人工规则作废）。同助手也被 `services/market.py` 与 `daily_recommend.py` 的内存层消费；新增进程内 TTL 缓存一律用它，不要手写时间戳样板。
- **Fetch chain & health beats** (`src/data/fetch_runner.py` + `src/data/source_health.py`): all fetch chains in `data_manager.py` (stock & index, zh_a & us) are ordered `(source_name, callable)` adapter lists executed by `run_source_chain` — the runner owns per-source fallback, warning logs, and exactly one `record_source_health(name, ok)` per source (untried sources get no beats). Exposed at `GET /api/data/source-health` (in-process, last 7 attempts, reset on restart) and rendered as the homepage 数据源心跳 widget. Adding a data source = appending one adapter to the chain; never hand-write the try/fallback/record pattern (the 12 scattered record call sites it replaced were the old way). Related: `Stock.get_stock_data` returns `pd.DataFrame` only — the `(df, file_name)` tuple was removed because every caller discarded file_name.
- **Backtest route seam** (`src/services/backtest.py`): the HTML `/run_backtest`, `/api/backtest/run`, `/api/strategies/compare` routes and the agent `run_backtest` tool must go through its `validate_backtest_params` / `run_json` / `run_with_charts` — 参数校验五连、market 白名单、基准映射（us→SP500 / zh_a→000300）都住在这里，不要在路由层复制。指标序列化只有 `backtest_manager` 内部 `_format_metrics_json` / `_format_metrics_percent` 一个出口（底层用 `src/utils/serialize`）。滑点始终启用——`config.yaml` 的 `backtest.slippage_enabled` 是从未接线的假开关，已删除。
- **`nes_data/trendradar/main.py` is NOT a normal importable module** (no proper package layout). `trendradar.py` *is* importable as `from nes_data.trendradar.trendradar import ...`, but in `src/` the shim `src/factor/trendradar.py` is the **only** channel — news fetching goes through its `get_recent_news(max_age)` (fresh-txt check → parse → crawl fallback, one place). Tests load `main.py` via `importlib.util.spec_from_file_location`. Don't `import nes_data.trendradar.main`, and don't import `nes_data.trendradar.trendradar` directly in `src/`.
- **Sentiment filter is look-ahead-safe**: backtests use only the snapshot dated on or before the backtest day, from `nes_data/sentiment_results/{YYYYMMDD}.json`. Don't introduce future-snapshot access.
- **Snapshot parsing contract**: the ONLY parser for `sentiment_results/*.json` is `src/data/sentiment_snapshots.py`（glob → 日期回退统一为 **文件名 → date 字段 → timestamp**，0-100 归一，缺失行业 fillna；`data_manager` re-export 保持旧 import 路径）。不要再在日历/回测/工具里手写第二份解析——历史上的三份实现曾对同一快照解析出不同交易日。
- **策略库 v2（代码策略，2026-09-17 起）——双轨真相**：**模板策略的唯一真相仍是 `strategies.json`**（`services/strategies.py` CRUD + TTL 缓存原样不动）；**代码策略**存业务 SQLite `src/store/db.py`（WAL、每线程连接、`QDT_STORE_DB_PATH` 可覆盖路径、启动清扫把遗留 queued/running 标 failed）。SDK 在仓库根 `emoquant/` 包（`emoquant.api` 交易 + `emoquant.data` 行情/情绪，`_runtime.py` 线程局部绑定宿主）；源码经 `src/Strategy/code_validator.py`（ast 白名单，封堵危险 import/调用/dunder 属性/getattr，定位"防呆不防恶"）+ `src/Strategy/code_loader.py`（exec 物化为 bt.Strategy 子类）加载。`_run_backtest_core` 的 `strategy_kind`（template|code）分支在策略解析 seam（598 行附近）——**代码策略不走模板的情绪软过滤**，SDK 另有 `eq_data.get_sentiment`（走 sentiment_snapshots 唯一解析器，永远只暴露当前交易日及之前）。**get_price 的 phase 语义**：initialize 阶段 end 缺省=回测结束日（一次性预热），handle_data 阶段=当前交易日（逐 bar 看不到未来）；显式 end 截断到回测结束日。**仓位不整手**——回测用后复权价非真实价格，整手约束无意义（percent 按可用资金封顶、取整到股；旧模板 stake=1 是历史既成口径，同信号 PnL 与代码策略不可直接比较）。策略**生效参数以 SQLite params 列为真相**（覆盖源码 STRATEGY_PARAMS 字面量默认值），调优/回写永远只 UPDATE DB 列不改源码；更新即自动快照版本（保留 20 条，`restore_version` 回滚）。
- **异步回测与运行历史**：`src/services/task_runner.py`（ThreadPoolExecutor + 看门狗）——超时是"放弃等待 + 标 failed"（Python 线程不可强杀，后台线程继续跑至自然结束；真隔离用 multiprocessing 属远期），终态写入全部条件 UPDATE 防迟到结果覆盖。运行记录唯一写入口是 `services/backtest_runs.py`（submit → create_run(queued) → 工作线程置 running → `_run_backtest_core(progress_cb=...)` 阶段计时 → finish/fail），equity 时序 zlib+base64 存 `backtest_runs`，**`/api/strategies/compare` 不落 runs**（保持无状态）。旧同步接口 `run_json`/`run_with_charts` 行为不变（`test_backtest.py` 特征测试护航）；v2 路由 `/api/v2/strategies*`、`/api/v2/backtest/runs*` 错误契约：ValueError 含"不存在"→404，否则 400。新环境变量：`QDT_STORE_DB_PATH` / `QDT_TASK_WORKERS` / `QDT_BACKTEST_TIMEOUT`（见 .env.example）。Agent 已有 3 个写工具 `create_strategy`/`update_strategy`/`get_strategy`（全部走 strategy_library 服务层），提示词内嵌 SDK 参考与 few-shot——**改 SDK 接口必须同步 `src/agent/prompts.py` 中英两份与前端示例模板（StrategyLibraryView 的 buildExampleSource）**。前端：`/strategy-library` + 详情页（CodeMirror 6 懒加载 chunk，`components/CodeEditor.vue`），词表 namespace `library.*`。
- **参数调优（P2）**：`src/services/tuning.py`——网格笛卡尔积 ≤63 候选 + 组合 0=基准（当前生效参数）；**组合结果只落 `tuning_runs`（指标 + ≤240 点降采样净值），不进 `backtest_runs`**（运行历史页保持用户手动发起的记录）；逐组参数经 `_run_backtest_core` 的 `strategy_params` seam 覆盖（code 绕开 DB 参数列、template 整体重写 parameters），**执行过程绝不回写策略存储**；唯一回写入口是 `apply_tuning_params`：code 合并网格键进 DB 参数列（经 update_code_strategy 自动快照版本）、template 走既有 `update_strategy` 写 strategies.json。执行=单个 task_runner 作业内嵌 `ThreadPoolExecutor(workers)` 并发跑组合、SQL 自增推进度计数；看门狗已泛化——`submit_task(..., on_abandon=fn)`，调优传 `_abandon_tuning`（任务+活跃组合一并标 failed），回测默认原行为；`tuning_tasks/tuning_runs` 的重启清扫并入 `db.init_db()`。前端：`/runs`（RunHistoryView，列表含 ≤60 点 `equity_preview`）+ `/tuning/:taskId` + 策略详情调优 Tab（新建对话框组合数实时笛卡尔积）；运行详情弹窗统一用 `components/RunDetailDialog.vue`（文案住 `runs.runDetail.*`）；**异步状态文案统一 `common.status.*`（library.status 已删除）**，指标展示名复用 `backtest.metric.<中文键>`，调优后端文案在 i18n 域 `tuning`。
- **Both frontends consume the same `/api/*` endpoints.** Jinja2 routes render server-side (`web/templates/`, `base.html` inheritance, `web/static/css/app.css` design tokens); the Vue3 SPA (`frontend/src/`) calls `/api` via axios and is mounted under `/spa/*`.
- **Bilingual UI (zh-CN/en-US), zero-dependency i18n（2026-09-16 起）**。SPA：`frontend/src/locales/index.ts` 手写引擎（响应式 `t(key, params)`，dot-path 查表，回退 en→zh→键名）+ 按视图分模块的 `locales/{common,layout,home,tour,backtest,compare,factor,sentiment,recommend,strategies,chat,palette}.ts`（每文件导出 `zh`/`en` 两棵对称消息树；**namespace 白名单=文件名**，跨页导航键只住 `layout.nav.*`，视图不得重复定义）。语言状态在 `stores/ui.ts` 的 `lang`（localStorage 持久化；`setLocale` 同步写 `emoqunt_lang` cookie，SPA 首访无 localStorage 时读 cookie 作初值）。**新增任何用户可见文案必须进词表双语言，禁止在组件里硬编码中文**。Jinja2/后端：`src/utils/i18n.py`（`emoqunt_lang` cookie → ContextVar 请求语言，Jinja 全局 `t(key, default, **params)` / `lang()` / `i18n_js()`，base.html 注入 `tt()` 助手供内联 JS）+ `src/utils/i18n_data/` 按域词表（`MESSAGES = {key: {"zh": 原文逐字, "en": ...}}`，新增域要注册进 `__init__.py` 的 `MESSAGE_MODULES`）。发射点翻译用 `vmsg(key, zh模板, **params)`（validators/daily_recommend 理由/agent tools），HTTP 边界错误用 `tr_error()`——**必须在中文子串状态路由（如 `"不存在" in error`）之后调用**。`GET|/api/set-lang?lang=&next=` 写 cookie 重定向。回测指标 JSON 键（`总收益率` 等）是 API 契约：**键不译，展示层经 `t('metric.<中文键>', 键)` 或前端 label map 翻译**；行情/板块/新闻等数据本身保持原语言。`src/agent/prompts.py` 按请求语言返回中/英系统提示词，`build_agent()` 缓存按语言分桶。README 截图：`docs/screenshots/_capture.py`（`--lang en` 出 `*-en.png`，选择器文案与 locales 同步维护）。
- **Data-heavy HTTP handlers must NOT block the event loop** (`web_app.py`): kline/sentiment/recommend/analyze/HTML-data handlers are plain `def` (FastAPI runs them in its threadpool); JSON-body POSTs (`/api/backtest/run`, `/api/strategies/compare`, `/api/factor/analyze`, `/api/agent/chat/sync`) stay `async def` but wrap the blocking service call in `await run_in_threadpool(...)`. Reverting these to `async def` + direct sync calls freezes the whole server for the duration of one slow akshare fetch (symptom: SPA chunk requests time out, navigation appears dead). The SSE `/api/agent/chat` is a true async generator — leave it.
- **SPA local persistence layer**: `frontend/src/stores/persist.ts` is a zero-dependency Pinia plugin (opt-in via `defineStore(id, setupFn, { persist: true | { key?, pick?, revive? } })`), persisting state to `localStorage` under the `emoqunt:` prefix with silent try/catch degradation. Persisted stores: `ui` (theme/sidebar collapse/tourDone/lang), `watchlist` (自选股 + last chart target), `backtestHistory` (回测摘要 + 上次表单, max 20 records), `chat` (messages, capped at 100, `streaming` flags stripped on revive), `favorites`/`homeLayout`/`tabs` (path+titleKey，渲染时经 t() 现算标题)/`klinePrefs`（K 线周期/复权/叠加/副图偏好；revive 负责旧裸键迁移）. **持久化 store 只存 id/键，绝不存 `t()` 的输出**（换语言即失效）。 The Jinja2 backtest form remembers last inputs via inline script in `web/templates/backtest_form.html` (key `emoqunt:backtest_form`; URL/query preselection wins over localStorage).
- **SPA deep modules**: `chart/kline.ts`（蜡烛图 scaffold 的唯一实现——市场配色/轴/十字光标/dataZoom/价格格式化，HomeView 与 BacktestView 共享；指标叠加与 markPoint 注记留在各自视图）、`lib/marketColors.ts`（**A股红涨绿跌·美股绿涨红跌的唯一规格来源**：DOM 侧 `deltaColor`、ECharts 侧 `chartPalette`、评分档位 `scoreColor`——新图表必须消费它，不要写裸 hex）、`lib/indicators.ts`（MA/EMA/BOLL/MACD/KDJ/RSI 纯函数；KDJ 参数是 [open, close, low, high] 序，见其签名文档）、`watchlist.openChartOnHome(target)`（"跳首页并预选标的"的唯一写法——禁止手拼 `code|market` 键，命令面板曾因此漂移）.
- **Chart target key is `code|market|kind`** (`targetKey` in `stores/watchlist.ts`): the third segment disambiguates A-share 二义 codes (000001 = 上证指数 as a `kind: 'index'` watchlist item vs 平安银行 as a stock). HomeView's active target, quote cache, and cross-page "open chart" jumps (chat tool cards, 个股推荐 click) all key on it; `ensureTracked()` adds-then-returns the key. The old 2-part `lastKey` format is normalized on load.
- **Agent chat SSE protocol** (`/api/agent/chat`): events are `token` / `tool_start` (tool began; result pending) / `tool` (complete result, JSON string truncated to 4000 chars for UI only — the LLM gets the full result) / `done` / `error`. `stores/chat.ts` pairs `tool_start`→`tool` fills and marks unanswered calls `failed` on stream end; `ChatToolCard.vue` maps known tool names to structured result cards (Generative-UI pattern), falling back to the raw collapse panel for unknown tools.
- **Homepage/nav UX benchmarks**: research on similar open-source projects (four rounds: FreqUI/OpenBB/Ghostfolio/admin templates → command palette/grid/tabs → KLineChart/leek-fund/Finviz heatmap → Lightweight Charts/Wealthfolio/NewsNow/driver.js) and the decisions taken from it live in `docs/research/homepage-ui-benchmark*.md` (+ `kline-chart-benchmark.md`). Round-4 Must/Should items were implemented on 2026-08-29: driver.js first-visit tour (lazy chunk, `stores/ui.tourDone`), watchlist sparklines/flash/polling (`usePolling`/`MiniSparkline`/`AnimNumber`), chat tool cards, and the BacktestView trade-marker chart.

## Testing quirks

- No `conftest.py` / `pytest.ini`. `test_backtest.py` manually inserts the project root into `sys.path`; `test_trendradar_notify.py` manually adds `nes_data/trendradar/` to `sys.path`. Keep that when adding tests.
- `test/test_trendradar_notify.py` are **characterization / golden-master tests**: on failure, update the expected value to match current output — do **not** change production `nes_data/trendradar/main.py` to satisfy them.
- `test/test_ak.py` and `test/check_cuda.py` are **manual scratch scripts** (no `test_*` functions). Don't treat them as the test suite.
- `TestSentimentSnapshots` in `test_backtest.py` `pytest.skip`s when no local sentiment snapshots exist, and asserts a specific mapping (e.g. `600938` 中国海油 → `石油行业`). It depends on real snapshot data under `nes_data/sentiment_results/`.

## Runtime / env

- Copy `.env.example` → `.env` (gitignored). Sentiment analysis needs `API_KEY` / `LLM_MODEL` / `LLM_BASE_URL` (OpenAI-compatible; default points at Xiaomi MiMo). `ZHI_TU_API_TOKEN` is referenced for the 智兔 data API. `TUSHARE_TOKEN` (optional, from tushare.pro) enables the Tushare primary tier of the A-share fallback chain; if unset the free sources handle everything.
- First backtest fetch of market/index data needs network access (akshare); results cache to `stock_data/` (subdirs `zh_a/`, `us/`, `stock_cache/`).
- `logs/`, `output/`, `nes_data/sentiment_results/`, `nes_data/trendradar/output/`, `stock_data/zh_a/`, `stock_data/stock_cache/` are gitignored runtime dirs auto-created on first run.

## Workflow

- Branch from `main`; PRs need at least one maintainer approval (per `CONTRIBUTING.md`).
- Codebase is bilingual: Chinese docstrings/comments/log messages + Chinese UI; English identifiers. Match the surrounding style.
